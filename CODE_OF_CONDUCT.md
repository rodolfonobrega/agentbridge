# Code of Conduct

We want agentbridge to be a welcoming project for everyone, regardless of experience, background or identity.

**Expected behavior:** be respectful and constructive, assume good faith, give and accept feedback graciously, focus on what is best for the project and the community.

**Unacceptable behavior:** harassment, insults, discrimination, personal attacks, publishing others' private information, trolling, or other conduct that would reasonably be considered inappropriate in a professional setting.

Maintainers may remove, edit or reject comments, commits, issues and other contributions that violate this code, and may temporarily or permanently ban contributors for behavior they deem inappropriate.

To report a problem, contact the maintainers through a private GitHub security advisory or the contact listed on the maintainer's GitHub profile. Reports are handled confidentially.

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
